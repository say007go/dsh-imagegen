# ImageGen

通过插件注册的 `image_generate` 工具完成生图，**优先用工具而不是手写脚本**。

> ⚠️ **防降级护栏**：若 `image_generate` 工具不可用（未注册/查不到），**不要手写脚本降级**——直接告诉用户"插件未加载，请重启 DSH 后开新会话重试"。任何情况下都**不要**把 API Key / SecretKey 明文写进脚本、工作区文件或对话。

## 工作流（强制，不可跳步）

1. **构建 prompt**：根据用户需求写 prompt。不要手动追加中文守卫后缀（工具会按配置自动加）。
2. **先向用户确认**：把最终 prompt 全文 + 本次尺寸（用户没指定就说明将用默认分辨率）展示给用户，并明确询问是否确认。用 `ask_user_question` 提问，或直接在回复里请用户确认。
3. **用户确认后**才调用 `image_generate`；用户要修改，改完重新确认。
4. **严禁**未经确认就调用工具，也**严禁**"先提交再说"。

## 等待与超时

- 生图通常 1~3 分钟，偶尔更久；工具会自动轮询（默认最多等 15 分钟），期间无需额外操作，也不要中途重复调用。
- 若返回超时错误，错误信息里带有**任务 ID**：说明任务可能仍在生成——**不要立刻再提交一个新任务**（会重复计费）。应告知用户任务仍在进行，稍后用同一 ID 查询或等待。

## 何时用哪个

| 用户意图 | 做法 |
|---------|------|
| 生成一张图（纯文字描述） | `image_generate` 只传 `prompt` |
| 用某张图做参考（图生图） | `image_generate` 传 `prompt` + `reference_images` |
| 测试生图配置是否连通 | 用一个小 prompt 文生图跑一次即可 |

## 参数要点

- `size`：临时指定分辨率（如 `1024x1024`），优先于配置里的默认分辨率。
- `reference_images`：
  - **URL**（生图站链接或 http 链接）→ 直接使用
  - **本地文件路径** → 工具会自动压缩并上传 COS 后使用
  - 多张参考图时，数组顺序即语义顺序，必要时在 prompt 里说明每张的用途
- **prompt 后缀**：插件配置里启用时，工具会自动在 prompt 末尾追加印刷级中文守卫——**无需在 prompt 里手写这段约束**。
- `enhance`：仅当用户明确要"原样 prompt、一个字都不加"时置 `false` 跳过追加。

## 结果呈现

`image_generate` 返回 `url`（生图站图片链接）时，用 `![描述](url)` 直接展示给用户，不要额外下载或转存，除非用户明确要求保存。
